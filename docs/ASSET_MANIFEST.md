# Asset Manifest — City of Small Chances

Authoritative map of **every art/audio asset** the game's milestones imply, what
exists, how each is produced, and which batch owns it. Generated by the
`asset-gap-scope` multi-agent scan (4 parallel readers over the design book +
codebase → synthesis → completeness critic) on 2026-06-15, then curated.

**Production methods:** `gpt-image-2` = painted via codex's built-in image_gen +
ImageMagick post-process (see `ART_PLAN.md`); `procedural-webaudio` = synthesised
at runtime in `src/three/audio.js` (no binary audio, no deps); `geometry` = built
from Three.js primitives.

> Honesty note (from the critic): this covers the **implemented 5-district slice**
> and a **functional procedural audio core**. Production-grade music, recorded
> voice, localization fonts, and the book's four *additional* canonical districts
> are **deferred** — tracked in *Known gaps* at the foot.

## Audio plan summary

No audio exists today (empty assets/audio/, no Web Audio code, the live build is silent) and there is no audio-generation tool available; the project's hard no-build/no-deps rule forbids Howler/FMOD/Wwise or any npm package. Therefore ALL sound is produced procedurally at runtime by a single new ES-module, src/three/audio.js, using only the Web Audio API plus the already-vendored Three.js (THREE.AudioListener on the camera + THREE.PositionalAudio for spatialised emitters), resolved through the existing importmap — no binary audio files are shipped. The module exposes a small init/resume + play API wired into the trigger points that exist TODAY in the thin src/three/ slice. (1) Ambient bed: a continuous low harbour sea loop (filtered-noise surf with a slow LFO), sparse synthesised gull cries, a non-verbal crowd/market murmur, a faint lamp electrical hum and localised shop-fan drones — all positional and mixed low; their density and gain track the SAME daycycle keyframes the visuals use (gulls/crowd thin after dusk, lamp hum fades up ~min 1140, a sparser colder deep-night bed enters ~min 1290 and on the midnight loop) by hooking the existing per-minute clock tick rather than a private timer. Weather beds (rain-on-awnings, rolling thunder, heat-wave cicada/fans) are authored now but gated on a weather state that still needs porting into the three slice. (2) SFX: player footsteps driven by the player.js gait phase (heavier at low energy, splashier when wet), quieter distance-attenuated NPC footfalls, per-beat work textures per job family (labour crate/barrel/container impacts, courier ticks, admin paper/stamp) cadenced from each job's task.tempo/beats, a shift-complete flourish, a warm earned coins-paid chime and a distinct lighter spend tone, a soft low-energy care-prompt, and a notice-board rustle. (3) UI/feedback tones — flat 2D so they stay equally legible everywhere: panel open/close, context-prompt tick, list select/move, a warm two-note CONFIRM and a soft non-mocking DENY (the deny always accompanies, never replaces, the on-screen plain-language reason — dignity + traceable-opportunity pillars), a gentler warning pulse, phone vibration buzz, an almost-subliminal time-block chime, and a subtle save tick. (4) Music is synthesised sparingly: a restrained warm harbour underscore and short stings (opportunity-discovered, morning, end-of-day reflection, relationship turn, final choice, tension) built from soft oscillator pads / piano-like tones — no heroic orchestration, spent only at the named strongest moments and ducked under everything readable. Hard rules honoured throughout: the AudioContext is created/resumed on the first user gesture (the existing input.js keydown/pointer handlers) to satisfy browser autoplay policy; beds and music duck so SFX/UI/voice stay legible (§22 mix discipline); every colour-coded state (open/locked, confirm/deny, warning, condition) gets a redundant sound paired with its icon+text as a genuine accessibility channel, and every cue exposes a caption string + duration so the UI can subtitle speech AND meaningful non-speech cues. Genuinely binary content that cannot be synthesised convincingly here — full musical themes at production quality, NPC voice barks/key-scene VO, and recorded crowd walla — is explicitly DEFERRED to a later real-recording/licensing pass; the procedural module covers all functional feedback and atmosphere the live walkable build needs now.
